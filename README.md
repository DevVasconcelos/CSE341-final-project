Popcorn API

Popcorn API is a simple and structured RESTful backend built with Node.js, Express, MongoDB, and Swagger.
It provides CRUD operations for Users, Movies, Genres, and Reviews, with clean documentation accessible through /api-docs.

Features

Lightweight and developer-friendly REST API

Full CRUD for all four collections

Mongoose models with validation

Centralized error handling

Swagger documentation

Fully deployed on Render

Technologies

Node.js

Express

MongoDB (Mongoose)
